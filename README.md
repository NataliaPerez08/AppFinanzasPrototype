# App Finanzas — prototipo Jetpack Compose

Prototipo navegable de las 8 vistas principales de App Finanzas con datos demo y estética neo-brutalista/editorial.

## Abrir
1. Descomprime el ZIP.
2. Abre la carpeta `AppFinanzasPrototype` en Android Studio.
3. Espera la sincronización de Gradle.
4. Ejecuta `app` en un emulador Android 8+ (API 26+).

## Incluye
Dashboard, Inversiones, detalle de inversión, alta de inversión, registro de movimiento, Patrimonio, Proyección y Configuración.

No incluye persistencia, backend ni cotizaciones reales: es un prototipo UI/navegación para validar UX antes de integrarlo al proyecto productivo.
